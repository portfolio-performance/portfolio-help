    加入翻译团队

    Portfolio Performance 目前已被翻译为多种语言。为了扩大其可及性并提升翻译质量，我们诚挚邀请贡献者加入我们的翻译团队。

    为什么要参与翻译？

    准确自然的翻译能让全球众多语言的使用者更容易、也更愉快地使用 Portfolio Performance。你的帮助将确保这款应用显得原生而精致。

    如何贡献新语言或协助翻译

    1. 在 POEditor 项目中注册
      如需开始贡献，请在此注册：
      加入 POEditor 项目
      所有翻译工作都在这个平台上进行和管理。

    2. 为新语言提交工单
      如果你计划添加一门全新的语言，并且需要测试版本或进一步支持，请在问题跟踪器中提交一个工单。这有助于我们协调并提供必要的资源。

    3. 翻译工作流
      在新版本发布之前，开发团队会从 POEditor 下载并合并所有更新后的翻译到 Portfolio Performance 代码库中。这可确保你的翻译被纳入下一次应用更新。

    翻译者须知

    • 尽可能翻译成你的母语
      为确保最高质量，我们强烈建议由母语者完成翻译，或由语言水平足以提供准确自然措辞的人完成翻译。

    • 🇬🇧 英语是参考语言
      所有翻译都基于英文源文本。翻译之前，务必清楚地理解英文的上下文和含义。

    如果你贡献代码

    如果你添加了需要翻译的新功能或新标签，请遵循以下准则：

    • 在 Portfolio Performance 中使用源文件 → 外置字符串，提取需要翻译的新字符串。这可确保所有新文本都被正确纳入资源文件。

    • 使用 ResourceBundle 编辑器编辑和格式化资源文件。来自 POEditor 的更新流程取决于该编辑器生成的格式，因此格式正确至关重要。

    • 对于新标签或新字符串，请将它们翻译成所有现有语言。你可以使用 DeepL 等机器翻译工具来加快初稿速度，但这些内容应由母语者审校。

    实用链接

    • 在 POEditor 上加入翻译项目
    • Portfolio Performance 的 GitHub 问题 —— 用于提交工单或协调沟通
