# 基本概念

本章将简明而清晰地解释若干基本概念。投资组合绩效说到底就是数字。若不理解其背后的假设，很容易把这些数字完全算错或误读。

- [金融术语](financial-terminology.md)：理解基本金融术语对用好 Portfolio Performance 与本手册至关重要。本页提供若干优秀站点的链接。

- [Portfolio Performance 术语表](portfolio-performance-terminology.md)：这是一份按字母顺序排列的简单词汇表，收录 Portfolio Performance 中使用的术语、缩写、列标题及其他相关词汇，并附各自定义。

- [系统概览](system-overview/index.md)：以鸟瞰视角说明 Portfolio Performance 如何运作。它讨论所有组件及其相互作用，聚焦于主要目标——计算投资组合绩效。另附[示例](system-overview/system-overview-example.md)。

- [账目](../reference/transaction/index.md)：金融交易是买卖双方达成协议，以支付为对价交换商品、服务或资产。就 PP 而言，交换的是证券。证券类账目包括买入、卖出、证券转入（inbound）与证券转出（outbound）；存款类账目包括存款、取款、利息、利息支出、费用、费用退款、税款、退税款；以及股息账目。

- [报告期](reporting-period.md)：报告期是为报告（计算、图表、统计）而纳入考虑的时间切片。必须意识到，每一次绩效计算都会纳入一个报告期，即便你并未显式设置。

- [成本](purchase-value.md)：证券的成本是该证券各项买入（+）与卖出（-）账目的金额之和，并计入[报告期](reporting-period.md)。一笔账目的金额包含税款与费用；有时也称为"净额"（Net Transaction Value）。

- [绩效](performance/index.md)：衡量投资组合绩效看似简单，实则涉及一系列需要解释的概念与计算技术。

- [历史价格](historical-prices.md)：为计算绩效，Portfolio Performance 需要两类历史价格：证券的历史报价，以及在投资境外资产时的历史汇率。
