要在本手册中解释所有金融概念，未免范围过大。然而，理解这些概念对于用好 Portfolio Performance 和本手册至关重要。

金融术语是一个复杂的主题，无法在一份指南中说透。要让投资的绩效变得可理解、可分析，就必须对金融工具及相关金融数学有基本认识。为此，我们在此汇编了一些链接，帮助你快速建立基础性的理解。

在本节中，你可以找到若干可靠的网页链接，以全面理解金融术语。与 Portfolio Performance 特别相关的概念（如账户、账目、成本）在本章其他部分另有说明。

- [Investopedia.com](https://www.investopedia.com/financial-term-dictionary-4769738) 有一个很大的金融术语板块，按字母顺序排列。
- 荷兰语读者可以查阅按字母顺序编排、内容详实的 [De Financiële Begrippenlijst](https://www.dfbonline.nl/)。
- [欧洲中央银行](https://www.ecb.europa.eu/services/glossary/html/glosse.en.html) 网站提供了内容丰富的金融术语与缩写词汇表。
- 网站 [iotafinance.com](https://www.iotafinance.com/en/Translations-of-Financial-Terms.html) 提供金融术语在英语、法语、西班牙语和德语之间的互译。
- [美国国会图书馆](https://www.loc.gov/static/services/federal-research-division/our-federal-research/documents/ENG-SPA-glossary.pdf) 提供一份 75 页的双语词汇表（英西双语）。
- [证券与股票之别](https://analyzingalpha.com/securities-vs-stocks#Stocks_Vs_Other_Types_of_Securities) 一文提供了若干历史背景，有助于理解 securities 与 stocks 的区别。

此外，下面还有一些其他资源，帮助你更深入地理解金融术语：

- [Boerse.de](https://www.boerse.de/boersenlexikon/A) 提供一本综合性的金融词典。若你对某个术语不熟悉，这里是首选去处。
- [Boerse-Frankfurt.de](https://www.boerse-frankfurt.de/wissen) 提供与股市和金融相关的各类主题信息。
- [Schweizer Handelszeitung](https://www.handelszeitung.ch/invest/finanzbegriffe-von-bis-z) 简明扼要地介绍了最重要的金融术语。
- [iotafinance](https://www.iotafinance.com/en/Translations-of-Financial-Terms.html) 是你在德语与英语之间转换金融术语时的首选资源。
