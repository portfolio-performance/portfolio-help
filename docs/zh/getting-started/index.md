要追踪、评估并管理你的证券，Portfolio Performance 需要你的证券账户与历史账目的基础数据。完成之后，你便可立即进行首次评估，从不同角度分析你的投资组合及其绩效。

## [安装](installation.md){#installation}
你可以使用预编译好的安装文件，也可以自行编译整个应用程序。Portfolio Performance 提供 macOS、Windows 与 Linux 版本。

## [创建投资组合文件](create-portfolio.md){#creating-a-portfolio-file}
第一步当然是创建一个新的投资组合文件，并把你的账户填入其中。投资组合文件包含全部证券、账户、证券账户、账目、分类等所有内容。

## [创建证券](adding-securities.md){#creating-a-security}
在证券列表中创建你关注的证券。主数据与历史价格由 Portfolio Performance 自动添加与更新。

## [管理投资组合](manage-portfolio/index.md){#managing-your-portfolio}
至此，你已创建好投资组合文件，并列入了一份自己关注的证券清单。现在是时候买入与卖出其中一些证券、收取股息，并设置储蓄计划了。

## [评估投资组合](measure-performance.md){#evaluating-your-portfolio}
绩效与风险评估十分重要，因此 Portfolio Performance 提供了多种评估与追踪方式。

## [对资产配置进行分类](classify-assets.md){#classifying-asset-allocations}
你用自己的分类体系来刻画各项资产的权重，例如按地区和/或按资产类别划分。

## [制定投资组合策略并执行再平衡](rebalancing.md){#defining-a-portfolio-strategy-and-performing-rebalancing}
你为不同资产类别设定目标值，从而刻画自己的投资组合策略。
你可以比较目标与实际，并执行再平衡。

## [保持投资组合数据最新](updating-portfolio.md){#keeping-the-portfolio-up-to-date}
你把新的买入、卖出与股息，以及发生的全部费用与税款记录在案。通过导入银行对账单 PDF，或手动维护数据，这项工作既快捷又简便。
