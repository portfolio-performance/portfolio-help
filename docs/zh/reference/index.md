`参考手册`围绕程序的用户界面（`UI`）来组织，为用户、开发者和贡献者提供一种便捷高效的方式定位相关信息。请注意，Apple 与 Windows 计算机上的菜单系统存在细微差异（Apple 见图 1，Windows 见图 2）。

=== "Apple 菜单"

    图： Apple 计算机的顶部菜单。{class=pp-figure}

    ![](images/menu-system-apple.svg)

    *请观看[此视频](../assets/videos/Menu-system-Portfolio-Performance.mp4)以了解这些菜单的实际用法。*

=== "Windows 菜单"

    图： Windows 计算机的顶部菜单。{class=pp-figure}

    ![](images/menu-system-windows.svg)

有若干菜单包含子菜单，例如 `文件` &rsaquo; `新建`、`文件` &rsaquo; `导入`、`视图` &rsaquo; `选项` 等。它们以 **:material-greater-than:** 符号标示。下面给出所有菜单与子菜单的文字表述。

手册 `参考` 一章的结构与程序的顶层菜单及子菜单一一对应，各章名称为 `文件`、`视图`、`账目`，或 `文件` &rsaquo; `导入`。请参阅本页的侧边栏；如果你是在小屏幕或移动设备上阅读，请查看 :material-menu: 汉堡菜单。
