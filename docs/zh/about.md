# 关于 Portfolio Performance

Portfolio Performance 是一款基于 Eclipse、用 Java 编写的桌面应用程序。这个开源项目始于 2012 年，此后已[多次更新](https://github.com/portfolio-performance/portfolio/releases)。借助 Portfolio Performance，你可以：

- 通过有意义的概览、关键指标与图表，监控证券投资组合的构成与变化。
- 追踪证券的历史价格走势，以及你的买入与卖出记录。
- 按需对组合中的证券进行分类，并以资产类别、地区等方式可视化其构成。
- 用计划中的资产配置定义并追踪你的投资组合策略，并在再平衡过程中确保其得以执行。
- 在多个证券账户与关联账户之间建立统一视图。
- 快速便捷地导入网上银行与券商的对账单。

为何还要再选一个应用程序？你当然可以用 Excel 模拟其中一些计算，或依赖券商提供的信息，但它们给出的结果往往不正确。这些结果通常仅基于报告期初与期末的绝对数值，无法正确纳入买卖账目或可变的报告期。Portfolio Performance 使用时间加权收益率与内部收益率准确计算绩效，并把买卖账目按各自的执行日期计入。
